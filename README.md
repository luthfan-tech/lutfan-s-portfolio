# Lutfan Mohammed Asif - Developer Portfolio

A premium, fully animated, glassmorphism-based personal portfolio.

## Setup Instructions

This project is built using a static architecture with HTML, Vanilla JS, and Tailwind CSS (via CDN) for zero-configuration deployment.

1. **Clone or download** the repository.
2. **Open `index.html`** in any modern web browser to view the site locally.
3. **Configure your email:** Open `assets/js/main.js`, locate the `copyEmail()` function at the bottom, and replace `"lutfan.mohammed@example.com"` with your actual email address.

## Deployment

Because this uses frontend technologies exclusively, it can be deployed for free instantly on platforms like:

- GitHub Pages
- Vercel
- Netlify

Simply link your GitHub repository to any of these services, set the root directory, and deploy.

## Built With

- **Structure:** HTML5
- **Styling:** Tailwind CSS (CDN), Custom CSS (Glassmorphism)
- **Interactivity:** Vanilla JS (Intersection Observer API)
- **Icons:** Phosphor Icons
- **Fonts:** Google Fonts (Space Grotesk, Inter)
